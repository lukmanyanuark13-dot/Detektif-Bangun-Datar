# Detektif-Bangun-Datar
Detektif Bangun Datar adalah game edukatif interaktif untuk belajar kekongruenan dan kesebangunan. Jadilah detektif yang memeriksa bangun-bangun misterius di Kota Geometri: bandingkan sisi dan sudut, lalu tentukan mana yang kongruen atau sebangun. Pecahkan kasus, raih lencana, dan naik pangkat jadi Detektif Senior!
